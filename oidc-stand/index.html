OIDC тестовый стенд

Минимальный OpenID Connect провайдер для проверки авторизации покупателя InSales с phone_number в claims. Код подтверждения в тест-режиме показывается на странице входа.

Значения для OAuth-приложения в админке InSales

ПолеЗначение
ID приложения (client_id)pushsaas-stand
API token (client_secret)задаётся в env STAND_CLIENT_SECRET
Issuerадрес этого деплоя, напр. https://<домен>

Endpoints

  • /.well-known/openid-configuration
  • /.well-known/jwks.json
  • /auth — страница входа (открывает InSales с параметрами)
  • /token — обмен кода на ID Token (server-to-server)
