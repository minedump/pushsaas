# Telegram Gateway — подключение для кодов подтверждения

Telegram Gateway (официальный сервис Telegram, [gateway.telegram.org](https://gateway.telegram.org)) доставляет
коды верификации в чат «Verification Codes» пользователя Telegram. Мы используем его как **второй канал каскада**
входа по телефону: `push (бесплатно) → Telegram ($0.01) → SMS (Bytehand)`.

## Почему это выгодно

- **$0.01 за доставленный код** — в десятки раз дешевле SMS (₽3–6).
- Недоставленные коды **не тарифицируются** (автоматический возврат).
- `checkSendAbility` — бесплатная предпроверка «дойдёт ли», поэтому каскад
  мгновенно падает в SMS для пользователей без Telegram, без потери времени и денег.
- Мгновенная доставка, нет уязвимостей SIM-swap.

## Шаг 1. Регистрация

1. Откройте [gateway.telegram.org](https://gateway.telegram.org) и войдите по своему номеру Telegram.
2. Заполните данные организации (принимают и ИП/самозанятых).
3. Пополните баланс (карта/крипта — см. раздел Billing кабинета). Для старта хватит $5–10.

> Тестировать можно бесплатно: коды на **собственный номер** (тот, под которым вошли в кабинет) не тарифицируются.

## Шаг 2. Получение API-токена

1. В кабинете Gateway откройте **API Settings**.
2. Скопируйте **Access Token** (строка вида `AAF…`).
3. Токен даёт право тратить баланс — храните как пароль.

## Шаг 3. Подключение к PushSaaS

1. Админка PushSaaS → проект → **Вход по телефону** → поле «Telegram Gateway token».
2. Вставьте токен, сохраните.
3. Канал `telegram` включится в каскад автоматически (переключатель там же).

Токен хранится в `project_secrets` (RLS: недоступен клиентским запросам, только service role).

## Как это работает под капотом

```
POST https://gatewayapi.telegram.org/checkSendAbility
  Authorization: Bearer <token>
  { "phone_number": "+79991234567" }
→ { ok: true, result: { request_id: "..." } }        # доставим; запрос бесплатный

POST https://gatewayapi.telegram.org/sendVerificationMessage
  Authorization: Bearer <token>
  { "phone_number": "+79991234567", "code": "123456", "ttl": 300, "request_id": "..." }
→ { ok: true }                                        # $0.01 спишется при доставке
```

Код генерируем мы (6 цифр, TTL 5 минут, 5 попыток ввода, не более 3 отправок на номер за 10 минут) —
см. `lib/otp/index.ts`. Обёртка API — `lib/otp/telegram.ts`.

## Ограничения

- Получатель должен быть пользователем Telegram и не скрывать номер от сервиса — иначе
  `checkSendAbility` вернёт отказ и каскад уйдёт в SMS.
- Отправка возможна только кодов верификации (не маркетинга) — правила Gateway.
- Если баланс Gateway пуст, канал молча выпадает из каскада (вход продолжает работать через SMS).
